# Форматы и правила синтетических задач

Padding — 0, разделитель/маркер — 1, выходной запрос — 2, полезные токены — 3..vocab_size−1. Цель вне loss_mask — −100. Дополнение справа; attention_mask описывает действительные позиции. Матрица причинности/локальности строится отдельно и не тождественна маске padding.

В JSONL сохраняются id, variant, input_ids, target_ids, attention_mask, loss_mask, latent, checksum. Checksum — SHA-256 канонической записи без поля checksum. NPZ содержит те же численные поля и ids; загрузка выполняется без pickle.

| Семейство | Наблюдаемый вход до шума | Цель |
|---|---|---|
| copy | payload, разделитель, выходные запросы | payload на выходных позициях |
| shift | чистая последовательность | токен слева на расстоянии 1+variant%3 |
| marker | последовательность с одним маркером и значением после него | значение после маркера на последней позиции |
| parity | двоичные признаки, закодированные 3/4, и запрос | паритет позиций 0,2,4,… как токен 3/4 |
| associative | пары уникальных ключей и значений, ключ запроса, выходной запрос | значение запрошенного ключа |
| induction | a,b,c,a,b,запрос | c |

Шум заменяет только полезные токены входа, не изменяя latent и правило цели. Поэтому при шуме вход может стать неоднозначным: oracle использует latent только для верификации данных, а не для оценки достижимого качества модели по повреждённому входу.

В associative пространства значений делятся по остатку modulo 3 между train/valid/test. Благодаря этому конкретные пары ключ–значение не пересекаются. Это соглашение также меняет распределение целевых токенов между split и усложняет перенос; его нельзя трактовать как одинаково распределённый тест. ID непересекаются во всех семействах; совпадения отдельных последовательностей в малых конечных пространствах возможны и должны отдельно учитываться в анализе студента.

В таблице Г.1 максимальная длина — верхняя граница. Фактическая длина copy и associative ограничена формой задания; контроль induction использует шесть позиций. Эта реализация задаёт один диагностический случай индукции, а не весь класс механизмов повторов.
